Cooked Collision Visibility

Fact-based implementation plan · 2026-08-28 · Research/evidence first

AGG GEOM FAILED RUNTIME TEST

The live raid dump found 48 static-mesh actors but zero spheres, boxes, capsules, convexes, or published primitives. AggGeom may be empty because Unreal stores complex collision in platform-specific UBodySetup::CookedFormatData. The old PhysX scene scanner also found no validated actor array.

Executive rule

Do not guess another collision layout. First capture one known wall/floor asset and identify its actual cooked format. No ESP wiring or ready state until the payload and one wall ray are validated.

Confirmed facts

  • Epic's UBodySetup owns both simplified AggGeom and platform-specific CookedFormatData.
  • PhysX cooked meshes are serialized binary data, not a raw vertex/index array; they require the matching PhysX interpretation.
  • Repository anchors: RootComponent 0x238, ComponentToWorld 0x370, WorldLocation 0x390, StaticMesh 0x728, BodySetup 0x1F0, AggGeom 0xB8.
  • WorldScan::CollectLevelActors() already enumerates level actors.

Stage 0 — evidence collection

For one known wall/floor actor, record actor, root, StaticMesh, BodySetup, all AggGeom TArrays, and a bounded 0x400–0x800 byte BodySetup window using chunked reads. Identify pointer/count/capacity candidates, cooked-format keys, byte-array pointer/size, and whether assets are shared.

Pass condition: a non-empty cooked entry with a recognizable format key and valid bounded bytes, or a separately validated live physics mesh, or a documented offline asset parser.

Stage 2 — parser/cache

After format identification, create CollisionMirror.h/.cpp. Deduplicate by StaticMesh/BodySetup, transform local geometry with verified ComponentToWorld including scale, publish immutable snapshots, bound DMA/asset/primitive counts, and reject malformed pointers/counts/bounds.

Stage 3 — geometry validation

  • Known wall ray blocks.
  • Ray outside/around wall passes.
  • Rotated/scaled geometry remains aligned.
  • Malformed/stale payload is skipped safely.
  • Runtime diagnostics include map, assets, cooked entries, format key, bytes, primitives, invalid entries, ray tests and hits.

Stage 4 — ESP wiring

actor.isVisible = !CollisionMirror::Ready()
               || CollisionMirror::LineOfSight(camera, targetPoint);

Warmup remains show-all. Wire only after Stage 3 passes; start with actor-origin LOS, then add per-bone LOS.

Stage 5 — cache/performance

Cache verified assets by build/map identity, rebuild on map transition or new assets, keep the background read budget bounded, and never reuse unknown-build geometry.

Reviewer checklist

  • Stage 0 wall/floor dump exists.
  • Cooked format/version identified.
  • Bounds and transforms validated.
  • Wall-blocking and wall-clearing rays pass.
  • No brute-force PhysX fallback.
  • Only then mark ready and wire ESP.
