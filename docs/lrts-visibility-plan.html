Arc Raiders LRTS Visibility

LastRenderTimeOnScreen · LRTS-only · plan only · 2026-08-28

NO GEOMETRY / NO PHYSX FALLBACK
Rule: do not build until the current game build proves the mesh pointer, BRR offset, candidate range, changing encrypted timestamp, and wall-stale behavior. Build-specific values are verification gates, not assumed facts.

Objective

Use each enemy skeletal mesh's encrypted LastRenderTimeOnScreen. Decode it and compare it to UWorld::TimeSeconds. A value close to world time means rendered/visible; a stale value means occluded.

Known field meanings

  • LRTS = LastRenderTimeOnScreen, intended occlusion-aware value.
  • LRT = LastRenderTime, frustum/render value only.
  • bRecentlyRendered is only a frustum signal for choosing a sample mesh.

Encryption

bits = byteswap(encrypted XOR key)
float value = bit_cast_float(bits)
key = candidate_raw XOR byteswap(worldTime_bits)

Stage 0 — mandatory evidence

  1. Confirm the supplied mesh pointer is the actual USkeletalMeshComponent.
  2. Verify BRR_OFFSET=0x997 and mask 0x20.
  3. Verify the scan range mesh+0x400..mesh+0x600.
  4. Confirm worldTime source/type/unit.
  5. Find a candidate that decrypts near worldTime and changes after ~120ms.
  6. Prove the selected field becomes stale behind a wall while LRT does not.

Stage 0 passes only with dynamic evidence. One plausible static float is not enough.

Stage 1 — isolated module

Project/Functions/LrtsVisibility.h
Project/Functions/LrtsVisibility.cpp

Expose Reset(world), Observe(mesh,time), and Check(mesh,time). Return Visible, Occluded, or Unknown. Unknown is used for warmup, bad reads, and unverified keys.

Stage 2 — discovery

  1. Scan only recently-rendered valid enemy meshes.
  2. Read the bounded candidate range.
  3. Derive provisional keys from worldTime.
  4. Wait ~120ms and require raw change plus time-consistent decoded value.
  5. Prefer a verified LRT/LRTS pair 4 or 8 bytes apart.
  6. Mark verified only after the dynamic test.

Stage 3 — key maintenance

Keep up to six verified session keys, delayed-verify new keys, reject duplicates, and reset all state on world changes. Never use an unverified key to hide a target.

Stage 4 — visibility

if (!verified || read_failed || no_key)
    return Unknown;

delta = worldTime - decodedLrts;
return abs(delta) < 0.5 ? Visible : Occluded;

Only Occluded maps to isVisible=false. Unknown remains shown.

Stage 5 — ESP wiring

After evidence and isolated tests pass, call the module only for admitted players/bots and replace the temporary isVisible=true. Do not add AggGeom, cooked collision, PhysX scene scanning, or another fallback.
