# CollisionRead 6 = the AggGeom reader behind UpgradeOptions::collisionProbe: a
# one-shot, off-by-default probe of UStaticMesh/BodySetup/FKAggregateGeom plus
# StaticMesh::ExtendedBounds, which is collision geometry the ESP frame does not
# carry and nothing else reads. The sixth site is the coarse occluder box: for a
# placed static mesh whose collision is complex-only and therefore does not decode,
# the probe records the asset's own bounds box as a world AABB so a level's walls
# are representable to the visibility scene at all. It reads the same offset the
# decode cross-check reads, but it is a separate site because it runs once per
# placement rather than up to kMaxBoundsChecks times. When the visibility stage
# lands, the per-asset cache it fills becomes the shared source and these sites
# belong in the frame rather than here.
# CollisionRead 8 = 6 + the two per-actor stand-in reads added with the
# actor-keyed geometry index. A player or a bot is a character: its root component
# is a CapsuleComponent and its mesh has no FKAggregateGeom, so the asset path
# never saw those 613 roots in a live probe and their shape outlines could not
# draw at all. Both new sites run once per actor INSIDE the existing walk, only
# while the probe is enabled, and neither is on the ESP or aim path: one 8-byte
# read of CapsuleComponent's half-height+radius (SDK 0x6b0/0x6b4, adjacent floats)
# and one of PrimitiveComponent::LocalBounds (SDK 0x710) as the fallback for any
# other primitive root. What they fill feeds the debug draw, not the BVH scene -
# a character's own capsule in the scene would occlude the character itself.
# CollisionRead 9 = 8 + one per-brush read of BrushComponent::BrushBodySetup (SDK
# 0x698). Brush roots (the walls and floors) are not StaticMeshComponents, so the
# static-mesh path never reached them and the visibility scene held no level
# geometry. Same shape as the stand-in reads above: one 8-byte pointer per brush
# root inside the existing walk, only while the probe is enabled, and it feeds the
# collision scene, not the ESP or aim path.
